# Accredian Landing Page Clone

A responsive clone of the Accredian landing page built using **Next.js**, **React**, and **Tailwind CSS**.

## Live Demo

The project is deployed on Vercel:

**https://accredian-landing-page-clone.vercel.app/**

---

## Setup Instructions

### Prerequisites

- Node.js (v18 or later)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd <project-folder>
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit:
   ```
   http://localhost:3000
   ```

Alternatively, you can view the deployed project here:

**https://accredian-landing-page-clone.vercel.app/**

## Approach Taken

The project was developed by breaking the landing page into small, reusable React components. Each section was built individually, ensuring it closely matched the provided design before moving on to the next section. This component-based approach keeps the code modular, maintainable, and easy to scale.

## AI Usage

AI tools were used to assist with basic development tasks:

- **ChatGPT** was used for basic programming assistance, troubleshooting, and generating boilerplate code for components.
- **GitHub Copilot** was used to speed up the development of basic components and repetitive code.

All AI-generated code was reviewed, modified where necessary, and integrated manually.
